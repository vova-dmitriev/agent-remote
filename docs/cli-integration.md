## Ordinary Claude terminal startup

Run `remote shell install` once to install an idempotent zsh integration, with a backup of the previous `.zshrc`. New interactive shells route `claude` through the owned PTY control channel. Local model/resume/settings flags are forwarded as arguments, without shell evaluation. Noninteractive invocation, print/JSON modes, background mode and administrative subcommands continue to call the original Claude executable. Native binaries and permission settings are unchanged.

Already running ordinary terminal sessions cannot acquire an owned stdin retroactively. The Mini App offers “Restart with input” when the companion verifies exactly one live native Claude process for that conversation. Clicking it terminates that exact process, waits for its exit, then opens Terminal with an owned launcher running `remote claude --resume` for the original native session ID and project. The remote session identity and history remain intact; the generation and input binding change. The companion captures the original executable, arguments and environment using the macOS native process helper before stopping anything. Explicit flags such as `--dangerously-skip-permissions`, model, settings and MCP configuration are preserved; old conversation selectors are replaced with the original session ID, and the initial prompt is not replayed. A private one-use payload transfers the environment to the new wrapper without putting secrets in a terminal command. For cmux, preflight verifies the original workspace and surface; the fixed launcher runs in that same surface. The companion must run inside cmux when its socket uses the default ancestry access policy. A denied socket or missing original surface fails before stopping the source; it never falls back to Terminal. A changed process identity, missing directory or uncertain stop prevents launching another writer. No terminal command needs to be copied. New sessions created in the Mini App already use the managed launcher.

Session list order uses the native timestamp of the last user/assistant message. Status/tool events and replay ingestion time do not promote a session. Clicking an open session's title edits an owner/device/native-source-scoped Agent Remote alias in PostgreSQL; subsequent native snapshots and reconnects preserve it. Native conversation titles are not mutated.

Codex Desktop recency uses the native `turnStartedAtMs` and per-message completion/start timestamp maps. CLI historical item pages use bounded native turn-time pagination. Missing timestamps remain unknown; reconnect time is never synthesized as message time. A replayed start notification for an already completed turn does not restore that turn to running.

Mini App sign-in renews a 15-minute access token using a 30-day absolute server-side browser session. Its cookie is HttpOnly, Secure on the public HTTPS origin, SameSite=Strict, and scoped to `/auth`. Refresh requires the configured Origin. Stale Telegram launch data must retain a valid signature and match the browser session owner; it does not replace authentication. Logout revokes all linked access tokens, closes their app sockets and clears the cookie, including when the original access token has expired.

Enter sends a composer message; Shift+Enter inserts a newline. IME composition and repeated keydown events never trigger a send. A restart receipt for the already open session does not reselect it or reload history. Layout changes during binding replacement preserve the visible reading line before paint, including when cmux terminal controls become available.
