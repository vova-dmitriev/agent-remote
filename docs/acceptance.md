- Публичный helper installer не подписан Developer ID и не нотарифицирован. Локальный архив проверен только для указанной platform/architecture/Node ABI.
- Настоящий cmux screen/input compatibility test не выполнялся в пользовательских панелях; ввод работает через собственный PTY child. Существующий произвольный terminal shell не перехватывается.

## Границы реализации

Один relay instance/bot poller, один active Mac/user, десять active sessions/device. Ended/disconnected sessions освобождают quota. История и dedup — 24 часа, до 10 000 событий/device; команды relay имеют TTL 15 секунд. Companion допускает до 15 секунд положительного рассогласования часов при проверке верхней границы TTL; просроченные по локальным часам команды отклоняет. Часы сервера и Mac должны быть синхронизированы.

После crash/disconnect неопределённый результат не означает, что Claude ничего не получил. Сначала проверяется исходный commandId. Companion restart не перехватывает прежний локальный frontend автоматически: может понадобиться локальный resume/restart.

Historical minor findings: notification deep links and original session titles were subsequently fixed. Completed notification outbox metadata still has no separate cleanup interval; an identical terminal snapshot with a changed capturedAt can be sent again. The Codex review and its regression fixes are recorded in the 2026-10-17 section above.

После приведения фронтенда: 82 Vitest checks (26 suites), 6 Playwright mobile checks и 33 Storybook browser/a11y scenarios. Финальные результаты и ограничения фиксируются в `.superpowers/current-status.md`; архив обновляется после итоговой сборки.

Нагрузочный harness использует реальные PostgreSQL и WebSocket; auth/pairing создаются через service methods с тестовыми identities. Измеряется relay event delivery; физический Telegram и Desktop этим benchmark не покрываются. Одновременно может идти предыдущий baseline profile: дополнительная нагрузка на ту же тестовую PostgreSQL отмечается в отчёте приёмки. Поздние изменения outbound frame cap проверяются отдельным полным профилем на версии после code freeze.

Переиспользование: собственные TypeScript rewrites с сохранёнными MIT notices выбранных подходов CCGram/cmux-tui; UI адаптирован к FSD с shared shadcn primitives. Автоматический importer upstream из task 0 не создавался, поскольку исходники целых upstream приложений не переносятся. Коммитов, push и публичного deploy нет.
